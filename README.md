# Relational Database Design & SQL

## Description
A relational database project developed as part of university coursework, focusing on database design, implementation and SQL queries.

The database models a shooting competition system, managing participants, shooting ranges, equipment, officials and competition results.

## Features
- **Database Design:** Relational database structure based on an ER model.
- **Table Relationships:** Primary and foreign keys to establish relationships between entities.
- **Data Management:** SQL operations for inserting, updating and deleting records.
- **SQL Queries:** Joins, subqueries, filtering, grouping and aggregate functions.
- **Data Modelling:** Implementation of relationships between multiple database entities.

## Technologies
- SQL
- MySQL
- Relational Database Design
- Entity-Relationship Modelling
- XML & DTD
